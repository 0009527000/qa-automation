# 性能测试记录（模板）

> **本文件不含任何实测数据。** 简历里「100 并发」「320ms → 95ms」这类表述，必须来自下面真实压测记录；没跑就不要写。

## 操作步骤

1. 用 JMeter（或 Locust）对查询、提交等核心接口建线程组，设置并发数、循环次数、持续时间。
2. 每次压测前记录：并发数、机器配置、被测环境、数据量、是否预热。
3. 保存 Aggregate Report（Average / P95 / TPS / Error%），前后各跑 3 次取均值，别只挑最好看的一次。
4. 打开 MySQL 慢查询日志，用 `EXPLAIN` 看 `type`、`key`、`rows`，定位未走索引的 SQL。
5. 加索引或改 SQL 后**用同样的并发数和环境再跑一次**，记录优化后数据。
6. 把 `.jmx` 脚本和报告截图放进本目录，并在下面填表。
